# ADR-0003: 年表記を DRY UP しない

- Status: Accepted
- Date: 2026-05-24

## 目的

スライド内の年表記（"2026"）の管理方法を決定する。

## 背景

2020 → 2026 更新（PR #65）の際、年が複数箇所に散在しており DRY UP すべきか検討した。

## 前提

- 年リテラルは `src/*.md` の title / description / 見出しに計13箇所、`marp.config.mjs` の footer に1箇所。
- 各 `.md` は素の markdown として標準的に読めるべき（驚き最小）。

## 選択肢

- A. `{{YEAR}}` プレースホルダ + engine フックで展開 … ⊖ 非標準のカスタム前処理。`.md` を読む人・AI が定義元に辿り着けず驚き最大
- B. `marp.config.mjs` に `const YEAR` を定義しフッターで参照 … ⊖ フッターは元々1箇所で repeat が無い。src の13箇所は DRY 化できず効果ゼロ。むしろ単一の真実源があるかのような誤った印象を与える
- **C. DRY UP しない。年変更時はリポジトリを grep して手修正** … ⊕ 標準的に読める・驚き最小 ⊖ 年変更が手作業（年1回程度で許容）

## 結論

**C を採用。** 手修正の手間は許容する。`marp.config.mjs` の footer は `2026` を直書きする。

補足: 一時 `const YEAR` がコードに混入していた（PR #65 の決定と不整合）が、issue #66 → PR #67 で除去し footer 直書きに統一済み。
